# Return Fraud Detector

**Zion Return Fraud Detector** — AI that detects return abuse, wardrobing, receipt fraud and refund-gaming patterns before they drain margin.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/return-fraud-detector/

## ✨ Features
- **Wardrobing detection** — flags buy-use-return cycles per customer, SKU and season.
- **Receipt & refund fraud scoring** — risk score on every return request with explainable reasons.
- **Serial returner graph** — links accounts, devices, addresses and payment instruments into one abuse graph.
- **Policy engine** — auto-approve good customers, step-up verification for risky ones.
- **Margin impact dashboard** — recovered revenue and avoided losses per store/channel.
